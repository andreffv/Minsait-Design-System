# Minsait Design System

Design system interno para projetos ligados à Minsait (ex.: Altova-MapFinder).

> **Estado:** estrutura inicial. Os valores de marca (cores, fontes, logótipos) ainda
> não foram carregados a partir de fontes oficiais e estão marcados como `PROVISÓRIO`.

## Estrutura

- `tokens/` – cores, tipografia e espaçamento
- `assets/` – logótipos, ícones e fontes (verificar licenças antes de adicionar)
- `docs/` – style guide e documentação
